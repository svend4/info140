MERIDIAN — Ткацкий станок тем
нити-основа = темы, каждое слово-уток пересекает свои темы. Связный текст даёт узор (живая зона); одна нить = монотон без узора (коллапс); случайный разброс без повторов = дыры/шум

режим:разброс (дробить) одна нить (обобщать)
Слева (разброс) каждое слово берёт новую случайную тему без повтора → нет вертикальных полос-узора, ткань в дырах = шум. Справа (одна нить) все слова в одной теме → монотонное полотно без узора = коллапс. В середине — несколько переплетённых нитей с повторяющимся мотивом = живой узор. Узорность = связность × разнообразие нитей. Файл: prototype/p42-theme-loom.html
