# Прототипы MERIDIAN (Проход 3)

Проход 3 строится **пошагово, от простого к сложному**. Каждый шаг имеет самостоятельную HTML-точку входа; поздние сложные прототипы используют небольшие локальные модули, не раздувая главный документ. Всё открывается напрямую или через XAMPP (`http://localhost/01/games/02/prototype/...`), а обмен между вкладками проверяется через localhost. Тема (светлая/тёмная) подхватывается автоматически.

## Полировка: звук + рекорды

Общий модуль [lib/mrd-fx.js](lib/mrd-fx.js) — WebAudio (фон/блипы/аккорды) + рекорды (localStorage). Подключение: `<script src="lib/mrd-fx.js"></script>`, доступ через `MRDFX`. Звук требует клика (политики автоплея) и слышен при открытии через XAMPP (`http://localhost/...`).

Ретрофит выполнен (вручную + роем агентов) практически во всех играх — у каждой кнопка «♪ звук»:
- **Со звуком и рекордом** (есть счёт): p3-alchemy, p4-flagship, p7-2048, p8-pulse, p9-foundry, p11-sieve, p12-resonance, p13-depot, p15-dispatcher, p16-metropolis, p20-flagship-3d, p25-cascade-rush.
- **Только звук** (визуализации/песочницы/PvP): p1, p2, p5, p6, p14, p17, p18, p19, p22. Встроенный звук изначально: p10-anthos, p21-smiley-city, p23-cascade.
