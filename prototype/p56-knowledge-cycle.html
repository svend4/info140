MERIDIAN — Цикл знаний ⇑⇓↔
полный двунаправленный конвейер Knowledge System (data7) на фразах, с операторами методологии info1: рассказ →⇓ концепты →⇑ «энциклопедия» →⇓ гипотезы из пробелов →↔ обратно в рассказ. Цикл питает сам себя: каждый прогон находит несвязанные темы и рождает новое — движение без конца

📕 Рассказ («диссертации» — конкретное)

—

⇓ Концепты (декомпозиция)

—

⇑ «Энциклопедия» (агрегация)

—

⇓ Гипотезы (синтез из пробелов ↔)

—

Метрики цикла

—
Декомпозиция = ⇓ (DissertationDecomposer: фразы → концепты-темы). Агрегация = ⇑ (WikiAggregator: главный концепт кластера — по частоте, как PageRank). Синтез = ⇓ (Synthesizer: пробел = пара тем, ни разу не встреченных в одной фразе → гипотеза-фраза с оценкой новизны). Замыкание = ↔ (info1): гипотезы вливаются в рассказ, закрывая пробелы; «связано пар» — накопление ↔-связей, растёт с каждым циклом (Φ). Файл: prototype/p56-knowledge-cycle.html
