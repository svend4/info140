## Цветовой код (сквозной)

Цвет кодирует уровень обобщённости класса инфона (один и тот же на D2, D5, D7):

- 🟣 пурпурный — C5 (ядро, самое общее, центр)
- 🔵 синий — C4 (порталы)
- 🟢 бирюзовый — C3 (статьи/темы)
- 🟩 зелёный — C2 (блоки/фразы)
- 🟠 янтарный — C1 (слова)
- 🟥 коралловый — C0 (кванты/буквы, самое дробное, край)
