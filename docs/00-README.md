# MERIDIAN — индекс проекта

> **MERIDIAN** — концепт компьютерной игры/симуляции о **производстве и удержании смысла** как физическом процессе.
> Это не «игра про частицы»: это замкнутая система, где «информационные атомы» (**инфоны**) кружат по гибридной геометрии (орбиты + Цветок жизни + метро-граф), сталкиваются, «общаются» и выстраиваются в очереди — как большой город с высоты птичьего полёта, — а игрок управляет ими через единственный **рычаг смысла λ**.

Это сводный индекс **Прохода 1** (теория + псевдокод). Документы серии — в этой же папке.

---

## 🎯 Идея в одном экране

Нельзя строить смысл «только из точки» (бесконечное **дробление** → буквы, цифры, шум; частица «вылетает из системы и исчезает») и нельзя «только обобщать» (бесконечное **слияние** → один заголовок-энциклопедия, которым «описан весь мир»; всё = ничто). **Оба полюса бесконечны и одинаково губительны.**

Поэтому их включают **обратно пропорционально, как рычаг**, в разных пропорциях, но **никогда на 100 %**:

```
        ДРОБЛЕНИЕ  ●━━━━━━━━━━━━━━━━━━━━━━━━━━━●  ОБОБЩЕНИЕ
       (шум, пыль)        λ ∈ (0,1)          (одно ядро)
        λ → 0      ↑ зона «жизни» смысла ↑     λ → 1
                    M(λ) максимальна внутри
```

- **λ (лямбда)** ∈ (0, 1) — строго внутри открытого интервала, никогда 0 и никогда 1.
- **Функция осмысленности** `M(λ) = K·λ^a·(1−λ)^b` (или операционно `vitality(λ)=4λ(1−λ)`) — единственный максимум внутри, нули на краях.
- **Закрытая система** (в духе таблицы Менделеева): инфоны не вылетают за границу, не сваливаются в центр (пробка/коллапс), не застывают; держатся законами сохранения.

## 📖 Глоссарий (сквозной для всей серии)

**Базовые понятия**
- **Смысл** — различимость элементов × связность целого; обнуляется на обоих краях.
- **Дробление / Расщепление** — полюс бесконечного деления (→ шум). λ→0.
- **Обобщение / Слияние** — полюс бесконечного слияния (→ одно ядро). λ→1.
- **λ (лямбда)** — управляющий рычаг ∈ (0,1), строго внутри.
- **M(λ) / vitality(λ)** — функция осмысленности; максимум внутри интервала.
- **Край хаоса (edge of chaos)** — зона максимальной «жизни» между порядком и хаосом.
- **Закрытая система** — конечный набор оболочек; ничто не вылетает/не коллапсирует/не застывает.

**Инфон и его модель** (см. [02](02-infons-closed-system.md))
- **Инфон** — частица-носитель смысла И транспортная единица одновременно («смайлик» города).
- **Масса m** — вес смысла (сохраняется). **Заряд q** — семантическая полярность (сохраняется).
- **Связность c / Энтропия s** — качество смысла (цельность vs раздробленность).
- **Валентность v** — число допустимых связей. **Спин** — ориентация/контекст.
- **Орбитальный уровень n** — «оболочка» обобщённости. **T½** — полупериод осмысленности.
- **Классы C0–C5** — кванты/буквы → слова → блоки → статьи → порталы → ядро-энциклопедия.
- **Инварианты I1–I5** — сохранение массы, заряда, популяции в коридоре, энергии, орбитального момента.
- **Химия смысла** — реакции дробления (распад) и слияния (синтез) под действием λ.

**Геометрия** (см. [03](03-geometry-topology.md))
- **Орбита** — концентрическая оболочка; радиус = ось рычага (центр=обобщение, край=дробление).
- **Цветок жизни / Шри Янтра / Бинду** — сакральная решётка узлов; недостижимый центр.
- **Метро-граф** — линии Lₖ, станции, пересадки, фазы φ поверх геометрии.
- **Master-узел** — один узел в трёх ролях: орбитальная точка + узел решётки + станция.
- **U_core / U_bound / U_flow** — потенциалы-запреты: анти-центр, удержание у границы, анти-застой.

**Логистика** (см. [04](04-logistics-dynamics.md))
- **Подтипы транспорта** — велосипед/легковой/автобус/троллейбус/трамвай/грузовик = классы инфонов.
- **Расписание-конвейер** — такты, фазы, волны отправления.
- **Фундаментальная диаграмма трафика** — поток-плотность-скорость; ρ_c (критическая), ρ_jam (затор).
- **Пустые улицы** — нижний порог ρ_min, штраф простоя (анти-застой).
- **Исходы встречи** — слияние / дробление / обмен / отталкивание / очередь / общение.

**Реализация** (см. [06](06-pseudocode.md))
- **World / Lever / Scheduler / Orbit / Node / Edge / Lane / Route** — структуры данных.
- **clamp_open** — гарантия λ ∈ (0,1). **split/merge** — реакции с сохранением массы и заряда.
- **edge_cost** — стоимость ребра с потенциалами центр/край + анти-пробочный вес.
- **balance_flows** — разгрузка пробок и оживление пустых улиц. **check_invariants** — проверка замкнутости.

| **10+** | P78, отдельные 1D/Q6-соседи и спецификации семантического ядра (p78–p80; docs 20–51) | **F1, Formula AST/span index, AG3, source-backed AG4 (review-only), post-hoc FlowFrame, внешний holdout-пилот, девять α-контрактов, Data7Adapter, EvidenceBackedLinkAdapter 1.4, method-only `QUALIFIES`, worker runner и пассивный evidence-backed view готовы; перенос пока `BLOCKED_FOR_AG5`, scheduler, α-view, Data7 ORBIT-view и AG5 не подключены** |

**Готово (Проход 4):** объёмный «Орбитарий» в двух версиях — [4a без зависимостей](../prototype/p5-orbitarium-pseudo3d.html) и [4b на Three.js](../prototype/p6-orbitarium-three.html). Подвариант C реализован в 3D.

**Готово (Проход 2):** 8 диаграмм в [docs/diagrams/](diagrams/README.md) — концепт-карта, орбиты/оболочки, граф «Цветок жизни», схема метро-конвейера, таблица инфонов, график `M(λ)`, диаграмма реакций, граф зависимостей объектов.

**Готово (Проход 3):** 4 интерактивных прототипа в [prototype/](../prototype/README.md) — 3.1 визуализатор геометрии, 3.2 песочница λ, 3.3 играбельная «Алхимия» (1D), 3.4 флагман «Рычаг смысла» (2.5D, с победой/поражением).

**Дальше:** внешний [holdout-пилот AG4](41-p78-ag4-external-holdout-baseline.md) уже зафиксировал `0/9` candidate recall и честно заблокировал AG5. [Спецификация осмысленного продолжения](42-p78-meaningful-continuation-and-information-recycling-spec.md) фиксирует следующий содержательный срез: отдельный development corpus, morphology, typed DefinitionClaim projector, continuation lattice, controlled realizer, replay и rollback; после них нужен новый blind holdout. Параллельная инфраструктурная ветка — `WorkSpec/WorkAttempt/WorkReceipt`, epoch registry и permutation tests настоящего scheduler. Текущая визуализация остаётся `POST_HOC_AG4_PROJECTION`. AG5 нельзя подключать, пока generated attempts не связаны с точными AG4 refs и не пройдены morphology, negation, budget и authority tests.

**Внешняя теория:** [критический аудит data2](43-p78-kryukov-motion-repository-adaptation.md) разрешает независимо реализовать петли, окна, FSM, масштабы и budgets как инженерные паттерны. LCI, нечётность, равенство частот и универсальные три сферы не входят в decision core без отдельных доказательств и corpus validation.

**Конвергенция P1-P80:** [кластерный речной конвейер](44-p1-p80-retrospective-and-cluster-river-conveyor.md) заменяет одинаковые капли на `SemanticCluster + ProvenanceManifest + FlowReceipt`, разделяет `G_sem/G_work/G_view` и связывает AG4.5 с реальной bounded queue и постоянным текстовым результатом.
**Девять семантических орбит:** [исправление аудита и спецификация α-автомата](45-p78-nine-semantic-orbits-and-alpha-automaton.md) возвращает уже описанную в документах 01, 03 и 16 архитектуру `info1`: полезные уровни `α=-4..+4` размещаются внутри безопасного 2D-кольца, тогда как 3D-коллапс и 1D-распад остаются за защитными зонами. Обобщение идёт внутрь, детализация наружу, связывание по касательной; цвет и радиус не получают семантической authority.
**Контракты α реализованы:** [исполняемый срез A](46-p78-alpha-orbit-contracts-implementation.md) добавляет девять content-addressed типов артефактов, typed edges и receipts для `GENERALIZE/SPECIALIZE/LINK/ORBIT/BRIDGE/PARK/ROLLBACK/ABSTAIN`. Модуль детерминирован, не имеет DOM/network/clock/random и публикует `semanticTruth:false`, `commitAllowed:false`; HTML и Canvas пока намеренно не изменены.
**Data7 проверен по отчетам и коду:** [критический аудит Knowledge System](47-data7-knowledge-system-form-content-and-p78-adaptation.md) разделяет реальный исполняемый граф/TSP-прототип, неподтверждённые семантические и production-заявления и уже выполненные адаптации P55/P56/P70. Для P78 разрешены только детерминированные draft-операторы с exact-source provenance, `semanticTruth:false`, `commitAllowed:false`; TSP управляет порядком внутри орбиты, а не истинностью.
**Data7Adapter частично подключён через evidence projector:** [исполняемый безопасный срез](48-p78-data7-adapter-implementation.md) создаёт exact-source Segment records, детерминированный directed-greedy порядок и `CO_OCCURS_WITH` candidate. P78 теперь использует Segment/Link для пассивной доказательной проекции; ORBIT и α-transition UI остаются автономными и не подключены.
**EvidenceBackedLinkAdapter v1 зафиксирован как историческая граница:** [воспроизводимый evidence gate](49-p78-evidence-backed-link-adapter-implementation.md) повторно разыменовывает SourceSnapshot, Claim AST, SourcePassage, SearchHit, context span, query/index provenance и alignment. Shape inspection никогда не объявляет referential replay выполненным.
**Направленный QUALIFIES подключён в пассивную проекцию:** [контракт с полным parser replay](50-p78-qualifier-direction-contract-implementation.md) доказывает только точный синтаксический delta `через <METHOD>`, связывает METHOD с точным source span и возвращает `DIRECTED/ABSTAIN`. `BROADER` остаётся диагностикой; EvidenceBackedLinkAdapter 1.4 создаёт `proposal/2` только для passage-relative `NARROWER`, а автоматический максимум остаётся `AlphaEdge(status:PROPOSED)`.
**Evidence-backed view подключён без command authority:** [projector, bound replay и пассивный View](51-p78-evidence-backed-link-view-implementation.md) строят точные Data7 endpoints в одном SourceSnapshot, полностью связывают отображаемые pins с validation receipt и показывают `PASSAGE -> TARGET`, `SOURCE_AUTHORITY_UNVERIFIED`, rejection/skip diagnostics и stale-clearing `ABSTAIN`. Replay выполняется Web Worker, а View рендерит detached immutable snapshot. Human review и commit отсутствуют.



**Граница научности:** радиус, жидкость, давление, гиперкуб и «масса смысла» являются инженерными метафорами или проверяемыми гипотезами интерфейса. Они не доказывают семантическую истинность; такое право может появиться только у отдельного source-backed review protocol.
