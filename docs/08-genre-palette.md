## Семейство 1 — Экшн/Аркада: рефлекс баланса между полюсами

### 1.1 MERIDIAN: Сито (Sieve Defense)
- **Жанр:** Tower Defense / reverse-TD на замкнутых орбитах · **Размерность:** 2.5D · **Сложность прототипа:** средняя
- **Переосмысление:** классический TD (Bloons, Kingdom Rush) наизнанку — убивать нельзя. Инфоны нельзя ни раздробить в шум (λ→0), ни слить в монолит (λ→1). Враги — это поток сырья, который надо переработать в нужный класс и довести до правильной станции живым. «Башни» — реакторы-катализаторы дробления/слияния на узлах. Цель перевёрнута: не «не пропусти», а «доведи в правильной форме и не перегни рычаг».
- **Петля:** волна инфонов C(n) выходит со станции-источника → игрок ставит/апгрейдит реакторы (дробитель −1 класс / синтезатор +1 / маршрутизатор / буфер) на узлах → ведёт потоки к приёмникам нужного класса → между волнами тратит ресурс на узлы и подкрутку λ.
- **Рычаг λ:** глобальный «наклон сита» ускоряет одни реакторы и тормозит противоположные; локально у каждого реактора свой мини-λ. Игрок балансирует около центра.
- **Инфоны:** одновременно враги, валюта и снаряды; масса сохраняется (видно на HUD).
- **Победа/поражение:** пережить N волн с M(λ) выше порога и заполненными квотами; поражение по полюсам — переполнение C0/C1-шумом (вылет за границу) либо C5-пробка (источники закупорены).
- **Эмоция:** спокойное мастерство диспетчера-инженера, удержание системы «на грани».
- **Прототип:** граф 6–8 узлов на 3 орбитах + 2 линии метро; инфоны-кружки едут по рёбрам (параметр t); узлы меняют класс/делят надвое; слайдер λ; MVP: 3 волны, 1 источник, 2 приёмника, λ-метр, счётчик M(λ).

### 1.2 MERIDIAN: Резонанс (Resonance Bullet-Garden)
- **Жанр:** bullet-hell / танец-уворачивание с инверсией поглощения · **2D** · средняя
- **Переосмысление:** Touhou/Ikaruga через λ и полярность. Пули — инфоны двух полярностей (Дробящие λ→0, Слипающие λ→1); кораблик-катализатор живёт только в узком коридоре λ. Вместо уворота — «настройка резонанса»: подбираешь свой λ, чтобы вражеский паттерн стал полезным инфоном. Полюса смертельны буквально.
- **Петля:** паттерн пуль из узора «Цветок жизни» в центре → игрок крутит λ и движется → ловит инфоны при совпадении λ (резонанс = поглощение + слияние в боезапас) → разряжает массу по боссу-ядру → уворачивается от противоположной полярности, не залипая у полюсов.
- **Рычаг λ:** главная ось управления (важнее движения); поглощение только при |λ_игрока − λ_инфона| мало; удержание у края наносит урон.
- **Инфоны:** пули И патроны; класс задаёт поведение (C0 рой квантов, C5 тяжёлое ядро); выстрел = дробление накопленной массы.
- **Победа/поражение:** довести босса-ядро до «живого равновесия» (стабилизировать M(λ)); поражение — не-резонансная пуля или залипание в полюсе.
- **Эмоция:** транс и точность «настройщика частоты».
- **Прототип:** эмиттер в центре, паттерны точек по полярным кривым (sin(kθ)); у точки polarity∈[0,1]; игрок-кружок с λ (цвет); коллизия по близости λ; две красные зоны у краёв тикают урон.

### 1.3 MERIDIAN: Конвейер-Метроном (Pulse Dispatch) ⭐
- **Жанр:** ритм-игра / rhythm-logistics диспетчера метро · **2D** · **низкая**
- **Переосмысление:** Thumper/Crypt of the NecroDancer/Vib-Ribbon + диспетчер-логистика. Расписание метро = партитура; ноты = окна отправления; промах = поезд ушёл недогруженным/переполненным, толкая систему к полюсу. Ритм = «пульс живой системы смысла».
- **Петля:** метроном задаёт бит → на станциях загораются окна отправления в такт → игрок жмёт по биту (и выбирает: дробить или слить груз) → поезда развозят инфоны, на пересадках реакции → темп нарастает.
- **Рычаг λ:** «свинг» метронома и режим обработки; идеал λ≈0.5 — ровный пульс; точность тайминга умножается на близость λ к центру.
- **Инфоны:** ноты-грузы (класс = высота тона, масса = длительность); «мелодия превращений» по замкнутому графу; сохранение массы = ритмический баланс.
- **Победа/поражение:** удержать комбо-грув N тактов в зелёной зоне M(λ); поражение — C5-пробка (пути встали) или C0-утечка за границу.
- **Эмоция:** грув дирижёра-диспетчера.
- **Прототип:** 2–3 станции на кольце; таймлайн с метками бита (кольцевой Guitar Hero); клик в окне ±120мс; свинг-слайдер λ; bit-clock на rAF, комбо, M(λ).

## Семейство 2 — Головоломка/Стратегия: дробление/слияние как ходы

### 2.1 MERIDIAN: Менделеев ⭐
- **Жанр:** пошаговая логическая головоломка-«химия» (sokoban-of-reactions / match-by-valence) · **2D** · **низкая**
- **Переосмысление:** SpaceChem + пасьянс-головоломки + сама Периодическая таблица как поле. Классы C0..C5 с «валентностью» на решётке «Цветок жизни». Новизна: ход не локален — он сдвигает глобальный λ (синтез вверх, распад вниз), поэтому каждая удачная локальная реакция приближает глобальную смерть. Головоломка со встроенным термостатом.
- **Петля:** осмотреть решётку → выбрать пару соседних для слияния (C2+C2→C3) или одиночный для дробления (C4→C2+C1+C1) → реакция перестраивает узор и двигает λ → собрать заданную «формулу» в центральном цветке, не уведя λ в красные зоны.
- **Рычаг λ:** глобальный термометр над полем; каждое слияние +Δλ, дробление −Δλ (величина зависит от классов); надо чередовать типы реакций.
- **Инфоны:** фишки-элементы (цвет+масса+валентность); масса сохраняется по доске.
- **Победа/поражение:** собран целевой узор при M(λ) выше порога за лимит ходов; поражение — λ дошёл до 0 (шум) или 1 (ком).
- **Эмоция:** аналитический азарт алхимика-шахматиста.
- **Прототип:** гекс-сетка 7×7, кружки с цифрой класса; клик по двум соседям = слияние, правый клик = дробление; бар λ с живой зоной; целевой узор в углу; таблица переходов классов.

### 2.2 MERIDIAN: 2048 Смысла ⭐
- **Жанр:** merge-головоломка с энтропией (2048/Threes! + менеджмент риска) · **2D** · **низкая**
- **Переосмысление:** 2048 наоборот. Слияние = обобщение: сливая C(n)+C(n)→C(n+1), тянешь λ к 1; достичь «наибольшей плитки» = проигрыш (коллапс в C5). Добавлен противоположный жест — РАСКОЛ (дробление, λ→0). 2048 учит копить — эта учит вовремя НЕ копить. Замкнутость: сумма масс постоянна, новые плитки только как продукты дробления.
- **Петля:** свайп сдвигает инфоны; одинаковые классы сливаются (+Δλ); альтернативный жест дробит крайнюю плитку (−Δλ); держать λ в центре и выполнять заказ уровня.
- **Рычаг λ:** индикатор средней массы/класса; у полюсов лавины — при λ→1 автослияние соседей (снежный ком), при λ→0 самодробление (шум); игрок гасит встречным действием.
- **Инфоны:** плитки на сетке 4×4/5×5; старшие классы ценны, но опасны для λ.
- **Победа/поражение:** выполнен заказ при λ в живой зоне; поражение — появилась C5 (λ→1) или поле в C0-шуме без ходов (λ→0).
- **Эмоция:** зудящий драйв 2048, вывернутый в тревожно-медитативный баланс; садовник, подрезающий смысл.
- **Прототип:** классический 2048 на Canvas + второй жест (Shift+стрелка = дробление); λ-бар как функция распределения; две лавины полюсов — пара правил. ~250 строк.

### 2.3 MERIDIAN: Диспетчер Смысла
- **Жанр:** программирование-автоматизация / логистический конвейер (Opus Magnum + Mini Metro) · **2.5D** · высокая
- **Переосмысление:** Zachtronics/Factorio + Mini Metro, но бесконечный рост запрещён: перепроизводство старших классов = обобщение (λ→1), раздёрганная логистика = дробление (λ→0). Оптимизируешь не throughput, а гомеостаз — лучшее решение держит M(λ) максимальным в стабильном цикле.
- **Петля:** размещаешь узлы-реакторы и тянешь линии метро с расписанием → запускаешь конвейер → инфоны едут, на узлах реагируют по твоим правилам → правишь схему, пока цикл не станет устойчивым и не выполнит квоту.
- **Рычаг λ:** агрегат сети; настраивается не ползунком, а архитектурой (соотношение дробителей/синтезаторов, длина маршрутов, частота поездов); цель — саморегулирующийся гомеостат.
- **Инфоны:** посылки-пассажиры; класс задаёт станцию назначения и применимый узел.
- **Победа/поражение:** устойчивый цикл, выполняющий квоту N тактов при λ в живой зоне; поражение — слипание в C5 (λ→1) или затор/потеря в C0-шум (λ→0).
- **Эмоция:** инженерный дзен Zachtronics — схема «задышала» и сама себя держит.
- **Прототип:** станции-узлы, мышью тянем линии (Mini Metro); 2–3 типа реакторов drag-and-drop; поезда-точки несут инфоны; тик на rAF пересчитывает λ; старт без расписания (по кругу).

## Семейство 3 — Симуляция/Рогалик: замкнутая логистика смысла

### 3.1 MERIDIAN: Депо Смысла (Depot of Meaning)
- **Жанр:** рогалик-забег с route-билдингом + dispatcher-сим (Slay the Spire × Mini Metro) · **2D** · средняя
- **Переосмысление:** Slay the Spire/FTL — вместо карт-атак прокладываешь маршруты инфонов между орбитами-станциями, «бой» = не сорваться в полюс. Mini Metro — пассажиры это инфоны C0..C5, перегруз станции = локальное дробление, пустые линии = обобщение. Забег = спуск/подъём по 6 оболочкам с боссом-полюсом.
- **Петля:** на каждой «остановке» видишь карту орбит и λ → тянешь линии → запускаешь конвейер на N тиков → реагируешь на события (всплеск C0, пробка у ядра) → собираешь реликвии (новые вагоны/правила) → к следующей оболочке.
- **Рычаг λ:** глобальное «здоровье» забега (M(λ)); дробление толкает λ→0, централизация λ→1; реликвии меняют коридор; босс давит λ к своему полюсу.
- **Инфоны:** груз, валюта и «карты»; реакции делят/суммируют массу; доставленные нужного класса = очки.
- **Победа/поражение:** пройти 6 оболочек, не дав λ коснуться 0/1 дольше grace-окна; поражение — срыв в полюс, открывается мета-прогресс.
- **Эмоция:** напряжение диспетчера на грани, азарт перезабега.
- **Прототип:** 6 станций по кольцу, тянем рёбра; инфоны-точки (lerp по сегментам); счётчик переполнения; λ как дисбаланс распределения; одна оболочка, один босс.

### 3.2 MERIDIAN: Фабрика Ядра (Idle Core Foundry) ⭐
- **Жанр:** idle/incremental клик-экономика с престижем (Cookie Clicker × Universal Paperclips), но с анти-целью · **2D** · **низкая**
- **Переосмысление:** Universal Paperclips наизнанку — бесконечный рост = смертельный полюс обобщения. Рост наказывается: чем выше производство, тем сильнее λ→1. Прогресс — в удержании потока живым. Престиж = осознанный «Большой Распад» ядра обратно в C0.
- **Петля:** кликаешь/автоматизируешь производство (C0→C1→…), строишь конвейеры дробления и слияния, балансируешь два встречных потока; покупаешь клапаны регулировки λ; периодически делаешь престиж за мета-валюту «резонанс».
- **Рычаг λ:** главный дашборд и единственный реальный ресурс-здоровье; доход ∝ M(λ)=4λ(1−λ) — жадность буквально обнуляет прибыль.
- **Инфоны:** ресурс и «население»; не исчезают (закон сохранения), очередь перед конвертером = пробка.
- **Победа/поражение:** нет классической победы — «долголетие потока» и рекорды; мягкое поражение — λ застрял у полюса, доход = 0; мета-победа — порог резонанса открывает новую оболочку.
- **Эмоция:** дзен-аддиктивность с подвохом; настройка органа, а не тупое накопление.
- **Прототип:** 6 полок-классов со счётчиками; кнопки «Дробить»/«Слить» переливают массу; λ = центр масс распределения; график M(λ); «резонанс/сек»; авто-кнопки после первой покупки; «Большой Распад».

### 3.3 MERIDIAN: Метрополис Оболочек (City of Shells)
- **Жанр:** city-builder / менеджмент транспортной сети с волнами спроса (Cities: Skylines × OpenTTD × Factorio) · **2.5D** · высокая
- **Переосмысление:** город = живая замкнутая система оболочек, «граждане» = инфоны, «районы» = орбиты по геометрии Цветка жизни. Ленты не производят на экспорт (выхода нет), а вечно циркулируют массу. Пробка = предвестник коллапса полюса.
- **Петля:** строишь сеть метро между станциями-орбитами, ставишь хабы-реакторы, задаёшь расписание → приходят волны спроса (оболочке не хватает C2, ядру избыток C5) → маршрутизируешь, расшиваешь пробки, расширяешь сеть.
- **Рычаг λ:** послойно (у каждой оболочки) и глобально; управляется архитектурой; цель — держать все оболочки в зелёном коридоре одновременно.
- **Инфоны:** пассажиропоток и строительный трафик; скопление без отвода = пробка → локальный полюс.
- **Победа/поражение:** устойчивое состояние всех 6 оболочек сквозь N волн; поражение — любая оболочка срывается, каскад роняет соседние.
- **Эмоция:** мудрый градостроитель-садовник замкнутого мира.
- **Прототип:** 3 кольца-оболочки со станциями, рисуем линии и ставим хаб (тоггл дробление/слияние); инфоны конвертируются на пересадках; волна раз в N сек; λ-кольцо меняет цвет от центра к полюсам.

## Семейство 4 — Нарратив/Эксперимент/Мультиплеер

### 4.1 MERIDIAN: Дыхание Цветка (Anthos) ⭐
- **Жанр:** нарративная медитативная zen-игра / interactive ambient · **2D** · **низкая**
- **Переосмысление:** Flower/Journey + Prune, но ты не толкаешь, а дышишь с системой. Вдох = λ→1 (инфоны слипаются в C5-ядро, узор наливается светом, звук густеет), выдох = λ→0 (ядро рассыпается на C0-кванты-буквы, ясный звон, но смысл дробится). «Не дроби и не обобщай до конца — живи в дыхании между полюсами».
- **Петля:** ритмично ведёшь λ вверх-вниз, узор Цветка жизни/Шри Янтры дышит; удержанный «идеальный вдох» около λ≈0.5 раскрывает следующий слой и строку поэтического нарратива. Ни таймера, ни очков.
- **Рычаг λ:** фаза дыхания; M(λ) управляет яркостью/гармонией звука (чище у центра, монотон/шум у полюсов).
- **Инфоны:** частицы-слова и частицы-света; на выдохе несут фрагменты фразы, на вдохе складывают её — «читаешь» нарратив ритмом дыхания.
- **Цель:** нет победы/поражения; пройти 7 «дыханий» (слоёв), каждое раскрывает строфу; «срыв» мягко меняет палитру, не наказывает.
- **Эмоция:** покой, присутствие, благоговение.
- **Прототип:** один rAF-цикл; lambda с lerp к курсору; Цветок жизни из окружностей (радиус/alpha = f(λ)); рой ~200 частиц (притяжение к центру при λ→1, расталкивание при λ→0); M=4λ(1−λ) → яркость + синусоида WebAudio.

### 4.2 MERIDIAN: Алхимический Верстак (Loom)
- **Жанр:** экспериментальный арт-тойс / sandbox без цели · **2.5D** · средняя
- **Переосмысление:** Powder Toy/Sandspiel/Conway, но стихии = классы инфонов C0..C5, а вместо гравитации — λ-поле как «температура реакций». Палитра — «периодическая таблица инфонов»; ставишь алхимические опыты.
- **Петля:** кидаешь инфоны, рисуешь λ-зоны кистью (горячие дробящие, холодные обобщающие, живые λ≈0.5), соединяешь станции линиями метро, смотришь каскады реакций; закольцовываешь потоки, сохраняешь seed.
- **Рычаг λ:** кисть/локальное поле на холсте; инфон реагирует по локальному λ (дробление при низком, слияние при высоком, равновесие у 0.5).
- **Инфоны:** «элементы» (масса, класс, валентность) и транспорт по линиям; масса сохраняется, не улетают за границу/в точку.
- **Цель:** нет (toy); необязательные челленджи-рецепты и галерея (осциллятор массы, симметрия Шри Янтры, удержать равновесие N сек); награда — красота и шаринг seed.
- **Эмоция:** любопытство экспериментатора, восторг эмерджентности.
- **Прототип:** частицы в типизированных массивах; λ-поле сетка 64×64 (кисть, билинейный сэмпл); тик: движение + правила реакции по локальному λ + сохранение массы; ~500 частиц, save-seed.

### 4.3 MERIDIAN: Разлом (Schism)
- **Жанр:** соревновательный асимметричный PvP / дуэль (1v1, локально/сеть) · **2.5D** · высокая
- **Переосмысление:** асимметрия Spy vs Spy + tug-of-war + территория Splatoon, но без стрельбы: дуэль философий. Дробитель (Шум) тянет λ→0, Обобщатель (Ядро) тянет λ→1 — «перетяни смысл мира к своему полюсу».
- **Петля:** общий рой инфонов C0..C5 на орбитах; глобальный λ = баланс сил. Дробитель кликами инициирует цепные распады (λ→0), Обобщатель сливает мелкие в ядра (λ→1); оба тратят «импульс» и ставят ловушки/катализаторы; раунд 60–90 сек.
- **Рычаг λ:** общая полоса-перетяжка («меридиан»); оба полюса гибельны, поэтому есть режимы «Перетяжка» (загони к своему полюсу) и «Равновесный» (кто дольше удержит λ в своём секторе, не убив систему).
- **Инфоны:** общий ресурс и поле боя; масса фиксирована (перераспределение, не накопление); можно перебрасывать на свою половину через пересадки.
- **Победа/поражение:** «Перетяжка» — загнать λ за порог соперника или перевес по таймеру; «Равновесный» — сумма секунд в своём секторе при живой системе; кто первым убьёт систему — проигрывает (самоподрыв).
- **Эмоция:** азарт асимметрии «мы играем в разные игры на одном поле».
- **Прототип:** общий стейт (hot-seat: ЛКМ игрок1, ПКМ игрок2; сеть позже через WebSocket); рой на орбитах; lambda += синтез − распад; клик дробителя → split ближайшего крупного, клик обобщателя → merge двух близких; HUD полоса-перетяжка с порогами.

## Что прототипировать (план Прохода 5)

По принципу «от простого к сложному» строим сперва четыре «низкой» сложности, максимально разные по ощущению:

1. **2048 Смысла** — кнопочная merge-головоломка, мгновенно понятна, ярко показывает «нельзя только сливать».
2. **Конвейер-Метроном** — ритм + логистика, даёт грув.
3. **Фабрика Ядра** — idle, показывает «жадность обнуляет прибыль» (доход = M(λ)).
4. **Дыхание Цветка** — zen/ambient, эмоциональный полюс палитры, красота геометрии.

Затем — средней сложности (Сито, Резонанс, Депо, Алхимический Верстак) и, при желании, высокой (Диспетчер, Метрополис, Разлом).
