# P78: маргинальный коридор 1D - 1.5D - 2D - 2.5D - 3D

## 1. Решение

P78 остаётся самостоятельной 2D-системой. Ему не требуется физический 1D- или
3D-движок для каждого шага. Соседние режимы нужны как границы и как типы
экспорта:

```text
1D       1.5D                 2D                    2.5D       3D
атомы -> фрагментация -> открытое продолжение -> жёсткость -> схема
```

`1.5D` и `2.5D` являются именами интерфейсных режимов. Это не заявления о
физической или топологической размерности.

- `1D` - предельная последовательность атомов: символы, двоичный код, Морзе,
  отдельные факты без рабочих мостов.
- `1.5D` - блоки ещё различимы, но связность распадается.
- `2D` - блоки связаны, допускают обратимое движение и следующий ход.
- `2.5D` - связей и ограничений уже много, движение ещё возможно, но система
  приближается к жёсткой схеме.
- `3D` - зафиксированная модель, онтология, тезис или другой консолидированный
  объект. Это результат экспорта, а не постоянное состояние кольца.

## 2. Почему jamming относится к 2.5D

Физический jamming описывает переход от подвижной системы частиц к
механической жёсткости. Поэтому он не является всей серединой P78 и не является
синонимом 2D.

В модели P78 ему соответствует только правая пограничная область:

```text
открытое 2D -> маргинальная жёсткость 2.5D -> фиксированное 3D
```

Работа Parisi и Zamponi рассматривает fullRSB-решение плотных твёрдых сфер в
пределе бесконечной размерности. Она не описывает двумерную жидкость P78.
Первоисточник: [A proof of an identity for the critical exponents of
jamming](https://arxiv.org/abs/2606.03300).

В статье:

```math
K = \int p_1(t) f(t)(1-f(t))\,dt,
```

```math
N = \int p_1(t) f(t)^2(1-f(t))\,dt,
```

```math
D = \int p_1(t)(f'(t))^2\,dt.
```

Алгебраическая идентичность имеет вид:

```math
c(D-2N)=(b-a-c)K=(1-a-b)K.
```

Для физической fullRSB-ветви используются:

```math
D=2N,\qquad K>0,
```

откуда:

```math
a+b=1.
```

Это теорема внутри указанной модели и набора предпосылок. Из неё не следует:

- что `f=0.5` является универсальной точкой jamming;
- что любой языковой граф обязан иметь `N/D=0.5`;
- что число треугольников можно без доказательства подставить вместо `N`;
- что значение `0.5` является целью семантического автомата.

## 3. Что дополняет сторону 1D

У jamming нет единственной симметричной теории-антипода. Для стороны распада
наиболее полезны три связанные области:

1. Теория перколяции - потеря глобальной связности при удалении связей.
2. Процессы фрагментации - распад кластеров на меньшие блоки.
3. Коагуляционно-фрагментационные процессы - совместное описание слияния и
   распада.

Классическая работа: [Erdős, Rényi, On the Evolution of Random
Graphs](https://users.renyi.hu/~p_erdos/1960-10.pdf).

Для случайного графа `G(n,c/n)` порог гигантской компоненты связан с `c=1`, а
её предельная доля удовлетворяет уравнению:

```math
S=1-e^{-cS}.
```

Это теорема для конкретной вероятностной модели. P78 не является случайным
графом `G(n,c/n)`, поэтому `c=1` не переносится в интерфейс как порог языка.
В runtime используются только наблюдаемые статистики уже построенного графа.

## 4. Роль теории Рамсея

Теория Рамсея задаёт глобальное ограничение роста: достаточно большой граф
неизбежно содержит либо клику заданного размера, либо независимое множество
заданного размера.

Первоисточник текущего обсуждения:
[Nearly tight exponents for off-diagonal Ramsey
numbers](https://arxiv.org/abs/2605.28793).

Для P78 это полезно как предупреждение о масштабировании, но не как локальная
формула движения:

```text
independent-set side  -> риск разреженности
clique side           -> риск избыточной связанности
между ними            -> не готовая формула, а область проектирования
```

Клика не равна 3D, независимое множество не равно 1D. Один связный граф может
иметь большое независимое множество. Конфликтное отношение также не равно
ребру клики. Поэтому runtime не вычисляет число Рамсея и не использует
асимптотику `r(s,k)` для отдельного предложения.

## 5. Три независимых слоя

Форму, грамматику и семантику нельзя сводить к одному числу.

### 5.1 Форма

Узлы:

- все вхождения слов, включая повторы и служебные слова;
- позиции;
- границы предложений.

Рёбра:

- соседство внутри одного предложения;
- повтор того же поверхностного или лемматизированного элемента.

Форма отвечает на вопросы:

- сохранилась ли последовательность;
- где она разделена;
- есть ли повторный ритм;
- возможен ли точный round-trip.

### 5.2 Грамматика

Узлы:

- вхождения слов.

Рёбра:

- согласование;
- валентность;
- субъектные и объектные зависимости;
- другие связи парсера.

Грамматический слой обязан показывать одновременно:

- статус;
- число проверок;
- число ошибок;
- открытые валентности;
- покрытие словаря или парсера.

`score=1` при отсутствии проверяемых конструкций не означает доказанную
грамматическую правильность. Такой случай должен давать `UNKNOWN` или
`ABSTAIN`.

### 5.3 Семантика

Узлы:

- нормализованные смысловые токены;
- утверждения;
- факты и источниковые опоры.

Рёбра:

- последовательность;
- мост;
- типизированное отношение;
- конфликт;
- evidence-backed relation.

Семантический слой не выводит истинность только из положения на Canvas.

```text
грамматичная фраза != истинная фраза
связанная фраза != доказанное утверждение
близкие слова != одинаковый смысл
```

## 6. Наблюдаемые графовые показатели

Пусть граф слоя имеет `n` узлов, `m` уникальных рёбер и `c` компонент
связности. Размеры компонент равны `|C_i|`, а:

```math
p_i=\frac{|C_i|}{n}.
```

Точные статистики графа:

```math
G=\frac{\max_i |C_i|}{n}
```

- доля узлов в крупнейшей компоненте;

```math
I=\frac{n_{\mathrm{isolated}}}{n}
```

- доля изолированных узлов;

```math
H_C=-\frac{\sum_i p_i\log p_i}{\log n}
```

- нормированная энтропия компонент;

```math
\mu=m-n+c
```

- цикломатическое число, то есть число независимых циклов.

Инженерные индексы P78:

```math
F=\frac{(1-G)+I+H_C}{3}
```

- давление фрагментации;

```math
R=\frac{\mu}{(n-1)(n-2)/2}
```

- нормированная избыточность циклических ограничений для `n>2`.

Формулы `F` и `R` являются адаптациями. Третья величина измеряет не новый
полюс, а способность системы продолжать обход:

```math
C=G(1-R)(1-0.35I).
```

Рабочая середина определяется тем, что наблюдаемая циркуляция поддерживает
оба давления:

```text
2D, если C >= 0.30 и C >= 0.90 max(F,R)
F - R >= 0.18 -> 1.5D
R - F >= 0.18 -> 2.5D
иначе          -> 2D
```

Пределы `1D` и `3D` проверяются раньше этих правил. Формулы `F`, `R`, `C` и
все числовые пороги являются инженерными адаптациями, а не теоремами о
языке; их надо калибровать на размеченном корпусе.

В семантическом слое дополнительно распознаётся явное намерение свести
различимые детали к одному окончательному тезису. Оно увеличивает давление
жёсткости и уменьшает циркуляцию. Это лексическая эвристика с отрицательным
контр-шаблоном (`не сводить`, `сохранить детали`), а не доказательство
обобщения и не вывод истины.

Позиция маркера:

```math
x_{\mathrm{rail}}=
\operatorname{clip}_{[0,1]}
\left(\frac12+\frac12(R-F)\right).
```

Левая сторона означает распад к 1D, правая - уплотнение к 3D.

## 7. Дискретная трасса, вдохновлённая jamming

Радиальная координата P78 имеет направление:

```text
u=0 -> 3D-центр
u=1 -> 1D-край
```

Для удобства вводится координата жёсткости:

```math
q_i=1-u_i.
```

Для реальных частиц semantic reaction field рассчитываются:

```math
K_\Delta=\langle q_i(1-q_i)\rangle,
```

```math
N_\Delta=\langle q_i^2(1-q_i)\rangle,
```

```math
D_\Delta=
\left\langle
(q_{i+1\bmod n}-q_i)^2
\right\rangle.
```

Также показывается нормированное расхождение:

```math
\operatorname{gap}=
\frac{|D_\Delta-2N_\Delta|}
{D_\Delta+2N_\Delta}.
```

Эта трасса нужна для сравнения профилей и будущей калибровки. Она имеет
контракт:

```text
diagnosticOnly = true
target = null
soundness = NOT_COMPUTED
```

`gap` не участвует в выборе режима. Тем самым P78 не выдаёт дискретную
подстановку за доказательство fullRSB-тождества.

## 9. Реакции системы

### 9.1 Сторона 1.5D

Условие:

```text
несколько блоков не имеют рабочих мостов
```

Результат:

```text
Связать два раздельных блока одним проверяемым мостом,
не сливая их в общий тезис.
```

### 9.2 Автономное 2D

Условие:

```text
есть маршрут, различимые детали и открытый следующий ход
```

Результат:

```text
Продолжить через один новый факт и оставить открытый мост
к следующему предложению.
```

### 9.3 Сторона 2.5D

Условие:

```text
много повторных или циклических ограничений,
но система ещё не экспортирована в фиксированную схему
```

Результат:

```text
Ослабить одно дублирующее ограничение и вернуть различимую деталь,
не разрывая основной маршрут.
```

## 10. Аудит диалога Grok

Конец файла `Grok_2026_07_24__1009.md` посвящён шрифтам Solan и локальному
калькулятору, а не завершению математической теории.

Корректно:

- скриншоты являются образцами глифов, а не автоматически расшифрованным
  текстом;
- Solan3 и Solan4 близки, но не полностью тождественны;
- локальный HTTP через XAMPP подходит для загрузки `@font-face`;
- формульные и графовые идеи полезно отделять от визуального алфавита.

Не доказано:

- что плотность глифа автоматически означает степень `D1/D2/D3`;
- что символ `#` обязан означать atomic cluster;
- что визуальный знак сам задаёт тип RAG-команды;
- что таблица клавиша - глиф - семантика подтверждена исходной документацией
  шрифта.

В математической части диалога были сделаны дополнительные переобобщения:

- `jamming = вся 2D-середина`;
- `f=0 = independent set`;
- `f=1 = clique`;
- `f=0.5 = точка jamming`;
- common-neighbor saturation якобы следует из статьи Parisi - Zamponi;
- отношение числа треугольников к вариациям обязано быть `0.5`;
- рамсеевская асимптотика масштаб-инвариантно управляет одной строкой текста.

Правильный порядок утверждений:

```text
наблюдение
-> интерфейсное соглашение
-> математическая адаптация
-> программный контракт
-> тест
-> калибровка
-> только затем рабочее правило
```

## 11. Что ещё не доказано

Текущий модуль остаётся экспериментальным:

- порог `0.18` не откалиброван;
- мини-парсер русского языка имеет ограниченный словарь;
- semantic graph строится эвристически;
- циклы графа не равны механическим контактам;
- форма, грамматика и семантика пока агрегируются фиксированными весами;
- нет внешнего корпуса с размеченными случаями `1.5D/2D/2.5D`;
- нет доказательства качества сгенерированного продолжения.

## 12. Следующий этап

1. Создать корпус не менее чем из 90 примеров: по 30 для распада, открытого
   продолжения и уплотнения.
2. Отделить calibration set от external holdout.
3. Калибровать порог и веса отдельно для формы, грамматики и семантики.
4. Добавить отдельный статус `CONFLICT`, который не считается размерностью.
5. Подключить полный dependency parser как необязательный адаптер.
6. Сравнивать прогноз режима до и после предлагаемого продолжения.
7. Разрешить экспорт:
   - в 1D только как точную обратимую последовательность;
   - в 3D только как типизированную схему с provenance;
   - обратно в 2D только через проверенный exchange contract.

Главное ограничение остаётся прежним:

```text
не удерживать систему искусственно в точке 0.5,
а сохранять возможность следующего осмысленного хода.
```
