## 1. Источник: алгоритм окон в кунг-фу (гл. 9)

Из «Тотальной системы боя», глава 9 «Логика движений»:

1. **Петля.** Движения руки идут по замкнутой траектории (круг → восьмёрка). Принцип **«нагруженного возвращения»**: рука после удара возвращается не «порожняком», а блоком — накрывает зоны атаки (стр. 42).
2. **Окно** = брешь в защите. В чужое окно бьют; своё закрывают блоком (стр. 40, 47).
3. **Тактовый конвейер ролей** (рис. 9.15): после удара бьющая рука сразу ладонью закрывает окно (блок), а вторая рука, блокировавшая тактом раньше, идёт на удар. В быстром темпе возникает «облако» ударов и блоков.
4. **Блок-схема открытия-закрытия окон** (рис. 9.13–9.14): 4 действия на 2 удара; каждое действие одновременно закрывает своё окно и **открывает-провоцирует** окно противника — **программирует** его на такт вперёд.
5. Три задачи алгоритма (стр. 45): а) последовательно закрывать бреши; б) провоцировать и запутывать; в) отслеживать действия противника (они запланированы вами) → «липкие руки».
6. **Камуфляж ↔ реальная угроза**: рука периодически меняет роль; нереализованный удар становится блоком и обратно (инь-ян).
7. **Усложнение петли вставкой**: в петлю из 3 участков вставляется новый фрагмент → петля из 4 (рис. 9.1–9.2) — окно петли открывается для нового элемента.

## 2. Мантра как оконный цикл

Маха-мантра, 16 позиций: `Х К Х К | К К Х Х | Х Р Х Р | Р Р Х Х`

- пара повторяется ×2 (окна закрыты — ритм, защита);
- повторы сгущаются (`К К Х Х`);
- **окно**: во второй половине цикла заменяется ровно одно слово (Кришна → Рама) при неизменном паттерне;
- весь цикл — петля высшего уровня (108 повторов).

Ритм повторов программирует ожидание — как блоки-провокации Винь-Чунь программируют противника; новое слово в предсказуемом окне получает максимальный вес.

## 3. Формализация: оконный ритм

**Определение.** Петля из n единиц × K повторов (окна закрыты) → 1 окно → петля обновлена.

- **Закрытое окно** = повтор: прочность связей растёт («нагруженное возвращение» — повторный проход чинит слабейшее ребро).
- **Окно** открывается **ритмично** (после K повторов), не случайно — детерминированный ритм новизны вместо вероятности (ключевое отличие от чистого ACO в p62/p63).
- **Впуск**: в окно входит один новый элемент, если его связность с петлёй ≥ θ; иначе — **блок** (откат, петля цела).
- **Окно-замена**: когда петля полна, вместо роста заменяется слабейшее звено (как Кришна→Рама).
- **Восьмёрка** = две петли с общим узлом = смена сектора/темы.

**Рычаг через K:** K=0 → каждый шаг новое = распад (шум); K→∞ → петля без окон = колея (застой); K=2–3 — живой ритм («слова повторяются 2–3 раза, потом повторы открываются, впуская новое»).

**Связь с ядром MERIDIAN:** повторы держат g (рост связного, закрепление), окна дают N (новизну) по расписанию, блок-отказ сохраняет κ (петля не гибнет) — оконный ритм = Φ (docs/12), развёрнутая в детерминированный метроном. K — это λ, выраженная временем.

## 4. Жанры — точки на рычаге

Жанр = настройки четырёх параметров (единица, петля n, K, порог θ):

| Жанр | Единица | K | Окно | Доля новизны (живая зона) |
|---|---|---|---|---|
| Барабанный ритм | доля такта | 3 | сбивка-филл в конце квадрата | 6–25% |
| Мантра | слово | 2 | замена одного слова | 2–15% |
| Песня (AABA) | мотив | 2 | часть B, каденция = κ_end | ~25% |
| Проза | тема фразы | 1 | одна новая рема на фразу (тема-рема) | ~50% |
| Белый стих | строка | 2–3 | смена анафоры (метр вместо рифмы) | 35–80% |
| Сюрреализм | образ | 0–1 | θ→0.1 (но не 0!) при целой грамматике | 55–95% |

Сюрреализм формулой: **валидность = 1, порог связности опущен, но не нулевой** — дальние темы при безупречном синтаксисе. «Бесцветные зелёные идеи яростно спят» — θ=0, за краем (верификатор p47 такое ловит).

**Многоголосие (p67):** здоровый ансамбль — не все голоса в середине, а **распределение по рычагу**: бас обязан быть колеёй (остинато), тенор — живым, искры — шумом. Здоровье оркестра = каждый голос в СВОЕЙ зоне.

## 5. Перенос в алгоритмы роя

- **p64**: петля слов + счётчик повторов + окно впуска/замены — базовый механизм.
- **p65**: три искусства одним движком; шкала новизны с жанровой зоной.
- **p66**: соединение с феромонами — сильнейшая тропа поётся куплетом; тропа держится = повторы, перестроилась = окно; испарение = рычаг обновления песни.
- **p67**: три феромонных памяти с разным испарением на одной сети = три голоса.
- Для роя-решателя (p51–p54): оконный ритм — замена вероятностной новизны детерминированной («когда 2–3 слова соединили и не хватает 4-го — включается окно»).

## 6. Открытые вопросы

1. **Адаптивное K**: менять K по обстановке (как боец меняет темп) — например, K растёт при высокой связности петли и падает при застое Φ.
2. **Провокация**: в бою окно не просто открывается — оно *провоцирует*; для генератора это значит открывать окно там, где ожидание читателя максимально (конец строфы, сильная доля). Формализовать «силу позиции».
3. **Гармония**: в p67 голоса независимы; следующий шаг — окна согласовывать между голосами (бас открывает окно → тенор отвечает), как вопрос-ответ в музыке.
4. **Липкие руки** для диалога: предугадывание на такт вперёд = модель собеседника; применимо к диалоговым агентам.

---

*Оконный ритм замыкает линию: боевая петля (кунг-фу) = молитвенный цикл (мантра) = квадрат с филлом (музыка) = тема-рема (речь) = ритм новизны роя (MERIDIAN). Одна структура, один рычаг, разные скорости.*
